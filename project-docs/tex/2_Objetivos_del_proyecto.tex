\capitulo{2}{Objetivos del proyecto}

El presente Trabajo Fin de Grado tiene como objetivo principal el desarrollo de un laboratorio virtual de programación y robótica, que permita a los estudiantes aprender programación mediante bloques, creado con c# y el motor de videojuegos de Unity 6. 
Para ello, se establecen los siguientes objetivos específicos:

\section {Objetivos funcionales }

Estos objetivos van a estar relacionados con las funcionalidades que el laboratorio virtual debe cumplir para ofrecer una experiencia educativa completa.

\begin{enumerate}
    \item Diseñar un sistema de bloques que replique fielmente la lógica y los procedimientos de Scratch.

    \begin{itemize}
        \item Bloques de movimiento, que permitan el desplazamiento del robot en diferentes direcciones.
        \item Bloques de control, como bucles y condicionales para la toma de decisiones.
        \item Bloques de sensores, para la introducción de valores para completar los bloques.
        \item Bloques de operadores, que permitan realizar operaciones matemáticas y lógicas.
        \item Bloques de eventos, que permitan ejecutar acciones en función de interacciones específicas tipo bucles.
        \item Bloques de variables, que permitan almacenar y modificar valores.
        \item Bloques de funciones, que permitan agrupar bloques y reutilizarlos.
    \end{itemize}



    \item Integrar este sistema en Unity, permitiendo la programación de robots.
    \begin{itemize}
        \item Crear un entorno de programación visual que permita arrastrar y soltar bloques.
        \item Implementar un sistema de ejecución de bloques.
        \item Crear un entorno de simulación que permita visualizar el comportamiento del robot.
        \item Diseñar escenarios y modelos 3D interactivos que permitan visualizar el comportamiento de los bloques de código.
        \item Implementar una interfaz intuitiva que facilite la programación y el uso del laboratorio.



    \item Adaptar el sistema de bloques al robot LEGO WEDO 2.0
    \begin{itemize}
        \item Crear bloques específicos para el control de los motores y sensores del robot.
        \item Implementar un sistema de comunicación entre el entorno de programación y el robot.
        \item Diseñar un entorno de simulación que permita visualizar el comportamiento del robot.
        \item Configurar bloques específicos para la utilización con el robot.
    \end{itemize}

\end{enumerate}

\section {Objetivos no funcionales}

Estos objetivos están enfocados en la accesibilidad, rendimiento y usabilidad del sistema.

\begin{enumerate}
    \item Accesibildad y escalibilidad
    \begin{itemize}
    
        \item Garantizar la accesibilidad del sistema a zonas con recursos limitados
        \item Diseñar una plataforma que pueda ejecutarse en distintos dispositivos sin requerimientos técnicos elevados.
        \item Permitir el acceso a contenidos educativos sin depender de equipamiento costoso.
        \item Explorar estrategias para que la herramienta pueda ser utilizada en contextos educativos con poca infraestructura tecnológica.
    \end{itemize}

    \item Investigación y análisis

    \begin{itemize}

        \item Investigar y analizar plataformas existentes como CoSpaces Edu, Robot Virtual Worlds, VEXcode VR y CoderZ.
        \item Identificar las ventajas y limitaciones de cada una y definir qué aspectos pueden ser mejorados en la solución propuesta.
    \end{itemize}

    \item Evaluación del sistema
    \begin{itemize}
        \item Evaluar la efectividad del sistema en la enseñanza de programación a estudiantes con diferentes niveles de experiencia.
        \item Realizar pruebas de usabilidad para medir la facilidad de uso del entorno de programación.
        \item Aplicar buenas prácticas de desarrollo en Unity y C\# para mejorar el rendimiento y estabilidad del sistema.

    \begin{itemize}

    \item formación
    \begin{itemize}
        \item Adquirir conocimientos en Unity relacionados con la creación de entornos interactivos y simulaciones educativas.
        \item Aplicar buenas prácticas en la integración de sistemas de programación visual dentro del motor de simulación.
    \end{itemize}
    \end{itemize}
\end{enumerate}
